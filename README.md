# 🐍 Python Learning – From Basics to Advanced

A comprehensive Python learning journey covering fundamental to advanced concepts, with hands-on code examples and detailed explanations. This repository demonstrates my Python programming skills and structured approach to learning.

---

## 📚 Topics Covered

### Day 1 – Python Fundamentals
| Topic | Description |
|-------|-------------|
| **Hello World** | First Python program and `print()` function |
| **Variables & Data Types** | Strings, integers, floats, type casting |
| **String Operations** | Concatenation, indexing, slicing |
| **Operators** | Arithmetic, comparison, logical, assignment |
| **Control Flow** | `if`, `elif`, `else`, nested conditions |
| **Loops** | `for` loops, `while` loops, `range()` |
| **Collections** | Lists, Tuples, Sets, Dictionaries |
| **Functions** | User-defined, built-in, parameters, return values |
| **Advanced Functions** | Default args, keyword args, `*args`, `**kwargs` |
| **Scope** | Local vs. global variables, nested functions |
| **Higher-Order Functions** | `map()`, `filter()`, `reduce()`, `zip()` |
| **Lambda Functions** | Anonymous functions with practical examples |
| **Identity vs Equality** | `is` vs `==` operators |

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Zain-Imran-09/Python-learning.git
   cd Python-learning
   ```

2. Open in Jupyter Notebook:
   ```bash
   jupyter notebook Day_1.ipynb
   ```

   Or open directly in VS Code with the Jupyter extension.
